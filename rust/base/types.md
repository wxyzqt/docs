# 语法

## 内建类型

内建类型 = 标量类型 + 复合类型

### 标量类型

1. 整型（Integer）

   - 有符号：`i8`, `i16`, `i32`, `i64`, `i128`, `isize`
     > > isize 的大小取决于目标平台的指针宽度
   - 无符号：`u8`, `u16`, `u32`, `u64`, `u128`, `usize`

2. 浮点型（Floating-point）

   - `f32`, `f64`

3. 布尔型（Boolean）

   - `bool`（值为 `true` 或 `false`）

4. 字符型（Character）

   - `char`（Unicode 标量值，4 字节）
     > > `let smiley = '😊';`

5. 单元类型（Unit）

   - `()`（无值，常用于函数返回值）
     > > 单元类型 () 只有一个值，就是 () 本身，表示“无值”或“无返回值”，但有实际类型。

### 复合类型

1. 数组（Array）

   - `[T; N]`（固定长度，元素类型相同）
     > > mut 声明时，元素可变

2. 元组（Tuple）
   - `(T1, T2, ...)`（长度和类型在定义时确定的组合）

## 自定义类型

- 结构体（struct）
- 枚举（enum）
- 联合体（union）

## 引用与指针类型

- 引用（`&T`、`&mut T`）
- 裸指针（`*const T`、`*mut T`）
  > > 裸指针的操作需要 unsafe 块包裹

## 函数与闭包类型

- 函数指针（`fn(T) -> U`）
- 闭包（`|args| { ... }`）

## Trait 对象类型

- `dyn Trait`

## 集合类型（标准库提供）

- `Vec<T>`、`HashMap<K, V>`、`String` 等
