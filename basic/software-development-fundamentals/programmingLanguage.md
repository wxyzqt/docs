# 编程语言对比

有一些朋友会问我如何选择编程语言，这里是我的一点看法。

首先，没有完美的编程语言，每一门编程语言都有其缺点，但更重要的是其应用领域。

针对不同人群情况，我推荐如下。

## 不从事软件行业

简单的想要运用程序帮助自己完成批量化的任务。

这种情况推荐 python，因为学习成本低，生态丰富。

这种情况下，不需要在意软件行业所谓的技术更新，兼容，原理，bug 等情况，也不用关注维护，仅仅自己用。

越简单，越容易出东西才是最佳选择。

## 从事软件行业，但只想做几年

以下只是个人了解，并不绝对。

世界范围来说，东亚地区的码农压力大，薪酬相对偏低，但在人口密度如此大的情况下，软件行业的薪水同地区对比也是相对能接受的行业。

“苦几年，攒点钱”的想法我也是理解认同的。

这种情况下，如果还有没有具体从事工作。

看学历选择，985 的硕博，211 定培专业，优先选择人工智能、算法岗、系统底层。

瞄准心仪的公司或行业，请教学长前辈自然知道该用什么编程语言，然后磕面试题和算法。

因为现在竞争相当激烈，非顶尖的学历可能难度有点过大。

做好次选和第三手的准备。

如果已经工作，那就在自己的领域好好深入两年，不必纠结。

因为等你各语言或者领域都大致摸一摸，就会发现：不过是命运将个体分配到不同的位置上，短时间内的随机性太大，而环境太复杂，非个人人力所能掌握。

## 想长期从事这个行业

绝大部分人在这个行业是呆不久的，如果已经有 5 年以上经验，想必已经知道该怎么走了。

估计此时犹豫的是，自己是否会因为方向选错被淘汰。

只能说，如果真的喜欢，这些问题都拦不住的。

答案只能自己寻找。

说了这些，其实编程语言基本没提，只想说“好好走每一段路，享受每一天”。

祝大家找到热爱的行业，一个不伤害身体的岗位，长期从事这行。

最后，我编程语言选择是：rust、js(nodejs)。

rust 用于系统编程和嵌入式，也将是我主攻的方向。

js 和 nodejs 用于交互、IO 和常规服务。
