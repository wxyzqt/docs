# 函数

| 知识类别      | 具体内容                             | 描述说明                                                                        |
| ------------- | ------------------------------------ | ------------------------------------------------------------------------------- |
| 函数定义      | `返回类型 函数名(参数列表) {函数体}` | 完整函数实现，包括声明和方法体。例如：`int add(int a, int b) { return a + b; }` |
| 函数声明      | `返回类型 函数名(参数列表);`         | 也称函数原型，仅声明不实现，告知编译器函数存在。例如：`int add(int, int);`      |
| 参数传递      | 值传递、引用传递、指针传递           | 值传递复制参数，引用/指针传递可直接操作原变量。                                 |
| 返回值        | 返回类型匹配、`void` 类型、返回引用  | 可返回基本类型、对象、引用或无返回值（`void`）。                                |
| 函数重载      | 同名函数，参数列表不同               | 允许同名函数根据参数类型、数量或顺序区分。                                      |
| 默认参数      | 参数设置默认值                       | 可省略有默认值的参数，默认参数需从右向左连续设置。                              |
| 内联函数      | `inline` 关键字                      | 建议编译器将函数代码插入调用处，减少调用开销。                                  |
| 函数指针      | `返回类型 (*指针名)(参数列表)`       | 指向函数的指针，可用于回调等。例如：`int (*pf)(int)`                            |
| Lambda 表达式 | `[捕获列表](参数){函数体}`           | C++11 引入的匿名函数，便于定义轻量级函数对象。                                  |
| 递归函数      | 函数调用自身                         | 通过自身调用解决问题，需设置终止条件避免无限递归。                              |
