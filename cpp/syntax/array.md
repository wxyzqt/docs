# 数组

| 知识类别     | 具体内容                         | 描述说明                             |
| ------------ | -------------------------------- | ------------------------------------ |
| 数组声明     | 类型 数组名[大小];               | 声明固定大小的数组，如 int arr[10];  |
| 初始化       | 数组名 = {值 1, 值 2, ...};      | 直接初始化数组元素                   |
| 访问元素     | 数组名[索引]                     | 通过索引访问元素，索引从 0 开始      |
| 数组大小     | sizeof(数组名)/sizeof(数组名[0]) | 计算数组元素个数                     |
| 多维数组     | `类型 数组名[行数][列数]`;       | 二维数组声明，如 `int matrix[3][4]`; |
| 数组指针     | `类型 (\*指针名)[列数]`;         | 指向二维数组的指针                   |
| 动态数组     | new 类型[大小];                  | 运行时分配内存的数组                 |
| 删除动态数组 | delete[] 数组名;                 | 释放动态分配的内存                   |
| 数组边界     | 避免越界访问                     | 索引需在 0 到大小-1 范围内           |
| 数组作为参数 | 函数(类型 数组名[], int 大小)    | 传递数组时需传递大小                 |
| 标准库容器   | std::array、std::vector          | 提供更安全和功能丰富的数组替代方案   |
