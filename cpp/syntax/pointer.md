# 指针

| 知识类别       | 具体内容                        | 描述说明                 |
| -------------- | ------------------------------- | ------------------------ |
| 指针声明       | `类型* 指针名;`                 | 声明指向特定类型的指针   |
| 取地址运算符   | `&变量名`                       | 获取变量的内存地址       |
| 解引用运算符   | `*指针名`                       | 通过指针访问指向的值     |
| 空指针         | `nullptr`                       | 表示指针不指向任何对象   |
| 指针初始化     | `类型* 指针名 = &变量;`         | 声明并初始化指针         |
| 指针运算       | `指针 + / - 整数`               | 指针移动，遍历数组元素   |
| 指针比较       | `指针1 == 指针2`                | 比较两个指针地址是否相同 |
| 指针类型转换   | `(类型*)指针`                   | 强制类型转换指针类型     |
| 指针数组       | `类型* 数组名[大小];`           | 声明指针数组             |
| 指向指针的指针 | `类型** 指针名;`                | 声明二级指针             |
| 动态内存分配   | `指针 = new 类型;`              | 分配堆内存并返回地址     |
| 释放内存       | `delete 指针;`                  | 释放通过 new 分配的内存  |
| 数组指针       | `类型 (*指针名)[大小];`         | 声明指向数组的指针       |
| 函数指针       | `返回类型 (*指针名)(参数列表);` | 声明指向函数的指针       |
