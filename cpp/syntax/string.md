# 字符串

| 知识类别     | 具体内容                             | 描述说明                         |
| ------------ | ------------------------------------ | -------------------------------- |
| 字符串类型   | `std::string`                        | C++ 标准库提供的动态字符串类     |
| 字符串声明   | `std::string str;`                   | 声明字符串变量                   |
| 初始化       | `str = "Hello";`                     | 通过字符串字面量或构造函数初始化 |
| 访问字符     | `str[index]`                         | 通过索引访问字符，索引从 0 开始  |
| 字符串长度   | `str.length()` 或 `str.size()`       | 获取字符串长度                   |
| 拼接操作     | `str1 + str2`                        | 使用 `+` 运算符拼接字符串        |
| 子串提取     | `str.substr(start, length)`          | 提取子字符串                     |
| 查找操作     | `str.find(substr)`                   | 查找子字符串首次出现的位置       |
| 修改操作     | `str.replace(start, length, newstr)` | 替换指定范围的子字符串           |
| 字符串比较   | `str1 == str2`                       | 比较字符串内容是否相等           |
| C 风格字符串 | `const char* cstr = "Hello";`        | 以字符数组形式存储字符串         |
| 转换操作     | `std::to_string(num)`                | 数值转为字符串                   |
| 输入输出     | `std::cin >> str;`                   | 从标准输入读取字符串             |
| 字符串流     | `std::stringstream ss;`              | 用于字符串格式化、解析和类型转换 |
