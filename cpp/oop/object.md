# 对象

| 类别       | 知识点               | 关键内容 / 语法                                                                   | 说明与生命周期                                                                        |
| :--------- | :------------------- | :-------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| 对象基础   | 对象定义             | `ClassName obj;`                                                                  | 对象是类的实例，分配在栈或堆上。                                                      |
|            | 对象与类关系         | 类是蓝图，对象是根据蓝图建造的房子。                                              | 一个类可创建多个对象，每个对象拥有独立成员变量。                                      |
|            | 访问对象成员         | `obj.member` </br> `ptr->member`                                                  | 点运算符用于对象，箭头运算符用于指针。                                                |
| 创建与销毁 | 栈上对象             | `ClassName obj(params);`                                                          | 作用域结束时自动析构并释放内存，生命周期由编译器管理。                                |
|            | 堆上对象（动态分配） | `ClassName* ptr = new ClassName(params);` </br> `delete ptr;`                     | 使用 `new` 创建，需手动 `delete` 销毁，否则内存泄漏。生命周期由程序员控制。           |
|            | 对象数组             | `ClassName arr[10];` </br> `ClassName* arr = new ClassName[n]; ... delete[] arr;` | 静态数组自动管理，动态数组需 `delete[]` 释放。                                        |
| 对象语义   | 拷贝语义             | `ClassName obj1 = obj2;` </br> `ClassName obj1(obj2);`                            | 触发拷贝构造函数。默认浅拷贝，有动态资源时需自定义深拷贝。                            |
|            | 赋值语义             | `obj1 = obj2;`                                                                    | 触发拷贝赋值运算符。动态资源需自定义深拷贝。                                          |
|            | 移动语义 (C++11)     | `ClassName obj1 = std::move(obj2);` </br> `obj1 = std::move(obj2);`               | 触发移动构造/赋值运算符。资源“转移”，源对象处于有效但未定义状态。高效避免不必要拷贝。 |
| 对象关系   | 组合（Has-A）        | 类 A 的成员变量是类 B 的对象。                                                    | 强拥有关系。A 的生命周期包含 B，B 随 A 创建和销毁。                                   |
|            | 聚合（Uses-A）       | 类 A 的成员变量是类 B 的指针或引用。                                              | 弱拥有关系。A 使用 B，但不负责 B 的生命周期。B 可在 A 外部创建和销毁。                |
| 对象特性   | `this` 指针          | 在成员函数内部，`this` 指向当前对象实例。                                         | 区分成员变量和参数，或返回自身。                                                      |
|            | `const` 对象         | `const ClassName obj;`                                                            | 常量对象，状态不可修改。只能调用 `const` 成员函数。                                   |
|            | 静态成员             | `static Type s_member;`                                                           | 属于类本身，所有对象共享。需类名限定访问。                                            |
|            | 友元                 | `friend`                                                                          | 授予其他函数或类访问私有/保护成员的权限。                                             |
