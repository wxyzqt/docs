# 寄存器

x86 架构，16、32、64 位寄存器

| 寄存器类型     | 寄存器         | 64 位寄存器 | 32 位寄存器 | 16 位寄存器            | 8 位寄存器(高 8 位,低 8 位) |
| :------------- | :------------- | :---------- | :---------- | :--------------------- | :-------------------------- |
| 通用寄存器     | 累加寄存器     | RAX         | EAX         | AX                     | AH , AL                     |
|                | 基址寄存器     | RBX         | EBX         | BX                     | BH, BL                      |
|                | 计数寄存器     | RCX         | ECX         | CX                     | CH , CL                     |
|                | 数据寄存器     | RDX         | EDX         | DX                     | DH , DL                     |
|                | 堆栈基指针     | RBP         | EBP         | BP                     |                             |
|                | 堆栈顶指针     | RSP         | ESP         | SP                     |                             |
|                | 源变址寄存器   | RSI         | ESI         | SI                     |                             |
|                | 扩展寄存器     | R8-R15      | R8D-R15D    | R8W-R15W               |                             |
| 指令指针寄存器 | 指令指针寄存器 | RIP         | EIP         | IP                     |                             |
| 标志寄存器     | 标志寄存器     | RFLAGS      | EFLAGS      | FLAGS                  |                             |
| 段寄存器       | 段寄存器       |             |             | CS, DS, SS, ES, FS, GS |                             |

- ‌8 位寄存器 ‌：通过拆分 16 位寄存器的高/低 8 位访问(如 AL=RAX 的低 8 位)。
- 扩展寄存器 ‌：64 位模式下新增 R8-R15，32/16 位模式下通过后缀 D/W 访问。
- 段寄存器 ‌：仅 16 位有效，64 位模式下功能受限
