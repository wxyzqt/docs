# 寄存器

x86 架构，16、32、64 位寄存器

## 通用寄存器

| 功能                        | 64 位寄存器 | 32 位寄存器 | 16 位寄存器 | 8 位寄存器(高 8 位,低 8 位) |
| :-------------------------- | :---------- | :---------- | :---------- | :-------------------------- |
| 累加器,运算结果存储         | RAX         | EAX         | AX          | AH , AL                     |
| 基址指针，数据访问          | RBX         | EBX         | BX          | BH, BL                      |
| 计数器(循环/串操作)         | RCX         | ECX         | CX          | CH , CL                     |
| 数据传递(与 AX 配合乘除)    | RDX         | EDX         | DX          | DH , DL                     |
| 函数调用参数传递(第 1 参数) | RDI         | EDI         |             |                             |
| 栈帧基址指针                | RBP         | EBP         | BP          |                             |
| 栈顶指针                    | RSP         | ESP         | SP          |                             |
| 数据源指针(串操作)          | RSI         | ESI         | SI          |                             |
| 新增通用数据存储            | R8-R15      | R8D-R15D    | R8W-R15W    |                             |

- ‌8 位寄存器 ‌：通过拆分 16 位寄存器的高/低 8 位访问(如 AL=RAX 的低 8 位)。
- 段寄存器 ‌：仅 16 位有效，64 位模式下功能受限

## 系统寄存器

| 寄存器类型     | 寄存器       | 功能                            |
| :------------- | :----------- | :------------------------------ |
| 控制寄存器     | CR0-CR4, CR8 | 控制 CPU 运行模式、分页机制等   |
| 标志寄存器     | RFLAGS       | 控制 CPU 运行模式、分页机制等   |
| 描述符表寄存器 | GDTR, IDTR   | 存储全局/中断描述符表基址和界限 |
| 调试寄存器     | DR0-DR7      | 硬件断点监控                    |

## 专用寄存器

| 寄存器  | 功能                                              |
| :------ | :------------------------------------------------ |
| RIP     | 64 位指令指针，存储下一条指令地址 ‌               |
| XMM0-15 | 128 位 SIMD 寄存器，用于浮点/向量运算 ‌           |
| FS/GS   | 64 位模式下可自定义基址的段寄存器(如线程局部存储) |
