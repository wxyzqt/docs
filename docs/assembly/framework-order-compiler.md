# 架构、指令集、编译器

## CPU 架构

汇编语言与特定 CPU 架构紧密绑定

| ‌‌ 指令集架构 | ‌ 名称/系列              | ‌ 主要特点                                     | ‌ 典型应用领域               | ‌ 代表处理器/平台 ‌             |
| :------------ | :----------------------- | :--------------------------------------------- | :--------------------------- | :------------------------------ |
| ‌‌x86         | x86 (IA-32)              | 复杂指令集（CISC），支持变长指令，向后兼容性强 | 个人电脑、服务器             | Intel Core、AMD Ryzen           |
|               | ‌x86-64 (AMD64/Intel 64) | x86 的 64 位扩展，增加寄存器数量和指令集       | 现代 PC、高性能计算          | AMD EPYC、Intel Xeon            |
| ARM           | ARMv7                    | 精简指令集（RISC），低功耗，32 位架构          | 移动设备、嵌入式系统         | Cortex-A8/A9                    |
|               | ‌ARMv8-A (64 位)         | 支持 64 位，兼容 ARMv7，增强性能和安全性       | 智能手机、平板、服务器       | Apple M 系列、高通骁龙          |
| ‌‌MIPS        | MIPS                     | 精简指令集（RISC），模块化设计，早期用于嵌入式 | 路由器、早期游戏机           | PlayStation 2、Cisco 路由器     |
| ‌‌RISC-V      | RISC-V                   | 开源精简指令集，模块化设计，可扩展             | 物联网、学术研究、新兴硬件   | SiFive 处理器                   |
| ‌‌PowerPC     | PowerPC                  | 高性能 RISC 架构，支持对称多处理               | 早期苹果电脑、游戏机、服务器 | IBM Power 系列、任天堂 GameCube |
| ‌‌SPARC       | SPARC                    | 精简指令集（RISC），支持多线程（如 T 系列）    | 企业级服务器、工作站         | Oracle SPARC 服务器             |
| ‌‌Z 架构      | z/Architecture           | IBM 大型机指令集，兼容旧版，支持高可靠性计算   | 金融、企业级大型机           | IBM z15                         |
| ‌‌AVR         | AVR                      | 8/16 位 RISC 架构，低功耗，哈佛结构            | 嵌入式系统、Arduino          | ATmel AVR 单片机                |
| ‌‌PIC         | PIC                      | 8/16 位精简指令集，专为嵌入式设计              | 工业控制、消费电子           | Microchip PIC 单片机            |

- ‌x86 与 ARM‌：x86 主导 PC/服务器市场，ARM 主导移动/嵌入式市场，两者在性能与功耗间各有侧重。
- RISC-V‌：开源指令集，近年快速发展，适用于定制化硬件和学术研究.
- 历史架构 ‌：如 MIPS、PowerPC 曾广泛使用，现多被 ARM 或 RISC-V 替代。

## 指令集

- 两种指令集设计方向：
  - CISC(复杂指令集),Complex Instruction Set Computing
  - RISC(精简指令集),Reduced Instruction Set Computer

|            | ‌‌CISC                                             | ‌RISC                                          |
| :--------- | :------------------------------------------------- | :--------------------------------------------- |
| 设计目标   | 减少指令数量，单条指令完成复杂操作                 | 简化指令，提高执行效率，通过编译器优化复杂操作 |
| 指令集特点 | 指令长度可变，功能复杂（如内存操作、算术逻辑混合） | 指令长度固定，功能单一（仅基础操作）           |
| 指令周期   | 多周期执行（因指令复杂度高）                       | 单周期执行（多数指令）                         |
| 寄存器使用 | ‌ 寄存器数量少，依赖内存操作                       | 寄存器数量多，减少内存访问                     |
| 硬件复杂度 | 高（需复杂译码电路、微码控制）                     | 低（硬件设计简单，流水线易实现）               |
| 编译器依赖 | ‌ 较低（硬件处理复杂逻辑）                         | 高（需编译器组合简单指令实现复杂功能）         |
| 功耗       | 较高（复杂电路和微码执行）                         | 较低（简化硬件和流水线优化）                   |
| 典型应用   | 传统 x86 架构（如 Intel/AMD 处理器）               | ARM、MIPS、RISC-V 等移动/嵌入式设备            |
| 代码密度   | 高（单条指令完成多操作，代码体积小）               | 低（需多条指令组合，代码体积较大）             |
| 执行效率   | 单条指令效率高，但并行性受限                       | 并行性强（适合流水线、超标量架构）             |

## 编译器

| 编译器名称 | 开发公司/维护者        | 语法风格     | 平台支持            | 输出格式支持        | 主要应用场景                   | 开源/商业 |
| :--------- | :--------------------- | :----------- | :------------------ | :------------------ | :----------------------------- | :-------- |

| NASM       | Netwide Assembler 社区 | Intel 风格   | Windows/Linux/macOS | ELF/COFF/bin/Mach-O | 系统内核、引导程序、跨平台项目 | 开源      |
| YASM       | NASM 衍生分支          | Intel 风格   | 跨平台              | ELF/COFF/PE         | 兼容 NASM 的替代方案           | 开源      |
| GAS        | GNU 项目               | AT&T 风格    | 类 Unix 系统        | ELF/COFF            | Linux 内核开发、GCC 工具链集成 | 开源      |
| TASM       | Borland                | 兼容 MASM    | DOS/Windows         | COM/EXE             | 老旧 DOS 程序维护              | 商业      |
| FASM       | 独立开发者             | 混合风格     | Windows/Linux       | PE/ELF/COFF         | 逆向工程、小型系统开发         | 开源      |

:::tip
c/c++在编译时会经过：预处理，编译，汇编，链接四步。

其中`编译`就是将预处理过的代码翻译为汇编语言。

`汇编`就是将翻译出来的汇编语言进一步翻译为机器指令。
:::
