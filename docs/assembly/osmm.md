# 操作系统模式内存布局

## 实模式

| 起始地址 | 大小       | 用途描述                                               |
| :------- | :--------- | :----------------------------------------------------- |
| 0x00000  | 1KB        | BIOS 中断向量表（存放 256 个中断处理程序的入口地址）   |
| 0x00400  | 256B       | BIOS 数据区（存储硬件检测结果等运行时数据）            |
| 0x00500  | 29KB+768B  | 可用内存区域（操作系统或程序可自由使用）               |
| 0x07C00  | 512B       | 引导扇区加载区（BIOS 将 MBR 或引导程序加载到此地址）   |
| 0x07E00  | 607KB+512B | 可用内存区域（主要供操作系统内核使用）                 |
| 0x9FC00  | 1KB        | 扩展 BIOS 数据区（存储高级配置信息）                   |
| 0xA0000  | 64KB       | 彩色显示适配器显存（EGA/VGA 图形模式下的显存映射）     |
| 0xB0000  | 32KB       | 黑白显示适配器显存（CGA/MDA 文本模式下的显存映射）     |
| 0xB8000  | 32KB       | 文本模式显示缓存（标准文本模式的显示缓冲区）           |
| 0xC0000  | 32KB       | 显示适配器 BIOS（存放显卡固件代码）                    |
| 0xC8000  | 160KB      | 硬件适配器 ROM 映射区（网卡、声卡等设备的固件映射）    |
| 0xF0000  | 64KB       | 主 BIOS 程序区（存放 BIOS 核心代码，入口地址 0xFFFF0） |
