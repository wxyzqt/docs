# 专业词汇

这里的词汇指的是在硬件和操作系统层面的专有名词。

对应 asm 和 c 语言的编程环境。

```md
PAS:physical address space,物理地址空间

RAM:random access memory,随机存取存储器，内存

ROM:read only memory,只读存储器

IVT:interrupt vector table,中断向量表

RTL:Run Time Library,运行时库

CRT:C Runtime Library,c 运行时库

VFD:virtual floppy drive,虚拟软盘驱动器

DOS:disk operating system,磁盘操作系统

LBA:linear block addressing,线性块寻址

TSS:Task State Segment,任务状态段

POST:Power On Self Test,加电自检

MBR:master boot record,主引导记录

GDT:‌global descriptor table‌,全局描述符表

LDT:local descriptor table‌,局部描述符表

IDT:interrupt descriptor table‌,中断描述符表

OEM:original equipment manufacturer,原始设备制造商

BPB:BIOS parameter block‌,磁盘参数块
```
