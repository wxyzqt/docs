# 汇编代码

## 清屏

```asm
mov ax, 3
int 0x10
```

86 实模式，
ax 设为 3，显示模式切换为文本模式(80x25 字符)。

此模式下，屏幕内容通过 int 0x10 进行控制
int 0x10 调用 bios 中断服务程序，

al=3，执行清屏，重新初始化显示区域
bh=0，设置新窗口的属性(颜色，字体)

## 引导扇区填充

```asm
times 510 - ($ - $$) db 0
db 0x55, 0xaa
```

times 510 表示重复 510 次
db 0 表示每次重复写入 0
$ 和 $$ 分别代表当前行号和代码总行数
减号计算剩余需要填充的字节数

db 0x55, 0xaa，是 MBR(主引导记录)的标准结束标识符。

`01010101 , 10101010`串联形成占空比为 50%的方波信号，有助于硬件识别信号完整性。
