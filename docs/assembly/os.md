# 操作系统

常规意义下的编程在这里发生。

操作系统将硬件抽象为文件，与普通用户隔离开来，同时提供预留的接口，让不同编程语言可以操作内存和寄存器。

内存和寄存器的操作在编程语言中则具象化为代码(指令)和数据。

## 权限

正常工作的硬件抽象为文件，具体操作分为`读、写、执行`三种

读`4`、写`2`、执行`1`，分别是 1 左移 2 位、1 位、0 位的位运算结果。

`chmod 755`对应所有者、所属组、其他用户三类用户。

## 进程和线程

一个程序默认至少包含一个进程。

进程是操作系统分配资源的基本单位，线程是进程内部的执行单元。

同一进程内，多个线程共享进程资源。

### 进程

#### 处理器资源

‌CPU 时间片：进程通过时间片轮转机制获得 CPU 执行权限，操作系统通过调度算法分配时间片以实现多任务并发

寄存器集：包括程序计数器(PC)、栈指针等寄存器值，用于保存进程执行现场

#### 内存资源

代码段(Text Section)‌：存储只读的可执行指令，多个进程可共享同一代码段

数据段：包含全局变量、静态变量(初始化和未初始化 BSS 区)

堆(Heap)‌：动态分配内存区域，通过 malloc/new 等函数管理

栈(Stack)‌：存储函数调用时的局部变量、参数及返回地址，每个线程拥有独立栈空间

#### 系统资源

文件描述符：用于访问文件和设备的标识符，包括标准输入/输出/错误流

‌I/O 设备：打印机、摄像头等硬件设备的独占或共享访问权限

网络资源：套接字、端口号等网络通信相关资源

#### 管理结构

进程控制块(PCB)‌：包含进程标识符(PID)、状态、优先级、内存指针等核心管理信息，是进程存在的唯一标志

用户权限：操作系统授予的权限级别，限制进程对敏感操作的访问

### 线程

#### 线程共享

- ‌ 内存空间 ‌

  - 代码段：所有线程执行相同的程序代码 ‌
  - 数据段（全局变量和静态变量）：线程可直接读写全局变量，需同步机制避免竞争 ‌
  - 堆区：动态分配的内存（如 malloc 或 new）由所有线程共享 ‌

- 文件与文件描述符 ‌

  - 进程打开的文件描述符（如日志文件、网络连接）被所有线程共享 ‌
  - 文件偏移量和状态标志在父子线程间共享

- 进程级资源 ‌

  - 动态链接库、信号处理器、当前工作目录、用户/组 ID‌
  - 进程 ID、调度优先级等进程属性 ‌

- 其他共享资源 ‌

  - 套接字和端口号（如网络连接）‌
  - 线程池中的任务队列或缓存对象（需同步控制

#### 线程独占

- ‌ 执行上下文 ‌

  - 栈空间：存储局部变量和函数调用链，每个线程独立 ‌
  - 寄存器组（如程序计数器 PC、栈指针 SP）‌

- 线程私有数据 ‌

  - 线程 ID、错误返回码、信号屏蔽码 ‌
  - 线程局部存储（TLS）变量 ‌

## 内存空间

程序的虚拟内存空间划分为用户空间和内核空间两大部分。

以 64 位 windows 为例

### 用户空间(低地址到高地址)

空指针赋值区(0x00000000~0x0000FFFF)：用于捕获空指针操作，触发程序崩溃。

可用用户空间(0x00010000~0x7FFEFFFF)：主要区域，包含代码段、数据段、堆和栈等，支持动态内存分配和函数调用。

保护页(0x7FFF0000~0x7FFFFFFF)：用户不可访问，用于检测越界指针。

扩展用户空间(64 位特有)：理论上可达 8TB，实际受限于系统配置。

### 内核空间划分(高地址)

- 内核模式地址范围(0xFFFF000000000000~0xFFFFFFFFFFFFFFFF)：总计 256TB，划分为多个固定用途区域 ‌
  - PTE 内存空间(512GB)：存储页表项 ‌
  - Hyper 内存空间(512GB)：虚拟化专用 ‌
  - 系统共享空间(4KB)：内核共享数据 ‌
  - 分页池区域(128GB)：内核动态内存分配 ‌
  - HAL 映射区(4MB)：硬件抽象层代码

## 宏内核和微内核

宏微内核的关键区别在于核心功能集成在内核中还是以用户态的形式运行。

理念和设计上来说微内核毋庸置疑更为先进，但在实现上，因为进程间通信(IPC)的巨大开销，导致微内核性能表现不佳。

鸿蒙微内核的 IC0、IC1、IC2 模式的分层是否真的好用，还有待时间验证。

## 指令集

指令集大致分为两大类：复杂指令集(CISC)和精简指令集(RISC)。

前者代表 X86，主要目标是复杂任务处理，多用于 pc 和服务器。

后者代表 ARM，主要目标是节能和执行效率，多用于移动端和小型设备。

指令集本身并不能代表厂商的水平，指令集的微架构硬件实现能力才是技术实力的衡量标准。
