## 数据结构分类

### 逻辑结构

表示数据元素之间的逻辑关系。

- 线性数据结构

  - 数组、链表、栈、队列、哈希表，元素之间是一对一的顺序关系。

- 非线性数据结构

  - 树、堆、哈希表，元素之间是一对多关系。
  - 图，元素之间是多对多关系。

### 物理结构

程序运行时，数据主要存储在内存中，系统通过内存地址来访问目标位置的数据。

物理结构反映了数据在计算机内存中的存储方式。

分为两大类：连续空间存储(数组)，分散空间存储(链表)。

数据的增删改查在两大分类的时间和空间效率上各有优劣。

所有数据结构都是基于二者或二者组合来实现。

基于数组实现：栈、队列、哈希表、树、堆、图、矩阵、张量（维度 ≥ 3 的数组）等。

基于链表实现：栈、队列、哈希表、树、堆、图等。

:::tip
很多编程语言中出现列表这一概念，将其等同于数组。

本质上，列表是动态数组，基于数组在空间上的连续性质，通过自动扩容实现动态变化。
:::

## 算法

算法是对数据结构的操作，以实现特定目标。

### 复杂度分析

算法的复杂度分析描述的是：随输入数据的增加，算法执行所需时间和空间的增长趋势。

时间复杂度从低到高排列有 𝑂(1)、𝑂(log 𝑛)、𝑂(𝑛)、𝑂(𝑛 log 𝑛)、𝑂(𝑛^2)、𝑂(2^𝑛) 和 𝑂(𝑛!)

空间复杂度从低到高排列有： 𝑂(1)、𝑂(log 𝑛)、𝑂(𝑛)、𝑂(𝑛^2) 和 𝑂(2^𝑛)

:::tip
在算法上，(log n)默认为 log 以 2 为底的对数。

绝大部分情况下，𝑛!、2^𝑛、𝑛^2，都是不能接受的算法。
:::
