# UEFI

当前 64 位操作系统主要使用 UEFI（Unified Extensible Firmware Interface）作为主流固件接口

基于 UEFI 固件的启动流程可分为硬件初始化、UEFI 固件阶段、内核加载和用户态初始化四个阶段

## 硬件初始化阶段

CPU 复位 ‌：加电后 CPU 从预设地址（x64 为 0xFFFFFFF0）跳转至 UEFI 固件入口 ‌

‌POST 自检 ‌：UEFI 执行硬件检测（内存、外设等），失败则终止启动 ‌

临时内存初始化 ‌：SEC 阶段利用 CPU 缓存（如 CAR 技术）建立临时存储区，为后续阶段提供运行环境 ‌

## UEFI 固件阶段

PEI 阶段 ‌：初始化内存、CPU 及芯片组关键设备，确定操作系统引导路径 ‌

‌DXE 阶段 ‌：加载 UEFI 驱动和固件所需资源，完成硬件抽象层（HAL）配置 ‌

‌BDS 阶段 ‌：选择启动设备（如 ESP 分区中的 bootx64.efi），初始化控制台设备 ‌

## 内核加载阶段

引导程序执行 ‌：UEFI 加载 bootmgfw.efi（Windows）或 grubx64.efi（Linux），传递控制权至内核

内核解压与初始化 ‌：解压内核镜像，设置 64 位保护模式，初始化进程调度、内存管理等核心模块

## 用户态初始化

系统服务启动 ‌：执行 systemd 或 init 进程，挂载根文件系统并加载驱动

用户登录 ‌：启动显示管理器（如 GDM），进入图形化登录界面

## 关键特性

安全启动 ‌：SEC 阶段作为可信根，验证后续阶段完整性 ‌

‌GPT 分区 ‌：UEFI 仅支持 GPT 分区表，支持 2TB 以上硬盘

快速启动 ‌：BDS 阶段直接加载 EFI 应用程序，跳过传统 BIOS 的复杂流程
