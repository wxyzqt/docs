# 汇编

c/c++在编译时会经过：预处理，编译，汇编，链接四步。

其中编译就是将预处理过的代码翻译为汇编语言。

汇编指令按功能分七大类：

‌ 传送类指令 ‌：用于寄存器、内存之间的数据移动，如 MOV、PUSH/POP、XCHG

‌ 算术运算类指令 ‌：包括加（ADD/ADC）、减（SUB/SBB）、乘除（MUL/DIV）及自增/减（INC/DEC）

‌ 位操作指令 ‌：涵盖逻辑运算（AND/OR/XOR/NOT）和位移操作（SHL/SHR）

‌ 串操作指令 ‌：处理连续内存数据，如字符串比较、传送

‌ 控制转移类指令 ‌：控制程序流程，包括跳转（JMP）、条件分支（JZ/JNZ）、循环（LOOP）及子程序调用（CALL/RET）

‌ 处理器控制类指令 ‌：管理 CPU 状态，如中断控制（INT/IRET）、标志位操作等

‌ 输入/输出类指令 ‌：实现 CPU 与外围设备的数据交互

按性质分三大类：机器指令、伪指令、宏指令

一个指令按照复杂度，消耗不同的时钟周期。

时钟周期：cpu 最小的震荡单位，或者说一次脉冲信号。

:::tip
汇编语言虽然基础原始，但也是一门编程语言。

编程语言操作的是内存和寄存器
:::
