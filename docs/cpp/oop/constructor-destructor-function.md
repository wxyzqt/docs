# 构造/析构函数

| 类别         | 函数类型             | 语法                                       | 调用时机与主要职责                                                                                                                               |
| :----------- | :------------------- | :----------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
| 构造函数     | 默认构造函数         | `ClassName();`                             | 当对象以 `ClassName obj;` 方式创建时调用。</br>若用户未定义任何构造函数，编译器会自动生成一个。                                                  |
|              | 带参构造函数         | `ClassName(Type param);`                   | 当对象以 `ClassName obj(param);` 方式创建时调用。用于初始化对象至特定状态。                                                                      |
|              | 拷贝构造函数         | `ClassName(const ClassName& other);`       | 1. 对象以拷贝方式初始化（`ClassName obj1 = obj2;`）</br>2. 传值参数</br>3. 返回值（某些情况下）</br>职责：创建一个新对象，使其成为原对象的副本。 |
|              | 移动构造函数 (C++11) | `ClassName(ClassName&& other) noexcept;`   | 当使用 `std::move` 或从临时对象初始化时调用。</br>职责：转移（“窃取”）源对象（通常是临时对象）的资源，避免不必要的深拷贝。                       |
|              | 委托构造函数         | `ClassName() : ClassName(0, "default") {}` | 构造函数间可以相互调用，避免代码重复。                                                                                                           |
|              | 转换构造函数         | `ClassName(Type param);` (单参数)          | 允许编译器进行从 `Type` 到 `ClassName` 的隐式类型转换。可用 `explicit` 关键字禁止。                                                              |
| 析构函数     | 析构函数             | `~ClassName();`                            | 当对象离开其作用域（栈对象）或被 `delete`（堆对象）时调用。</br>职责：释放对象在生命周期内申请的资源（如动态内存、文件句柄等）。                 |
| 关键特性     | 初始化列表           | `ClassName(Type p) : member_(p) {}`        | 必须用于初始化：</br>1. `const` 成员</br>2. 引用成员</br>3. 没有默认构造函数的类类型成员</br>推荐用于所有成员，效率高于在函数体内赋值。          |
|              | 构造/析构顺序        |                                            | 构造：基类 → 成员 → 自身</br>析构：自身 → 成员 → 基类（与构造严格相反）                                                                          |
|              | `= default` (C++11)  | `ClassName() = default;`                   | 显式指示编译器生成默认版本的函数。                                                                                                               |
|              | `= delete` (C++11)   | `ClassName(const ClassName&) = delete;`    | 显式禁止编译器生成某个函数，例如禁止拷贝。                                                                                                       |
| 继承中的行为 | 派生类构造函数       | `Derived() : Base(params) { ... }`         | 默认调用基类的默认构造函数。若要调用基类的带参构造，必须通过初始化列表显式指定。                                                                 |
|              | 虚析构函数           | `virtual ~Base();`                         | 准则：当一个类打算被继承（多态使用）时，其析构函数必须声明为虚函数。                                                                             |
| 特殊案例     | `explicit` 关键字    | `explicit ClassName(int value);`           | 阻止构造函数被用于隐式类型转换，只能用于显式构造。                                                                                               |
