# 继承

| 类别       | 知识点             | 关键内容 / 语法                                       | 说明                                                                                                                                           |
| :--------- | :----------------- | :---------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| 基础结构   | 继承方式           | `class Derived : public Base { ... };`                | 默认 `private` 继承；可指定 `public`/`protected`/`private`，控制派生类对基类成员的访问级别                                                     |
|            | 访问控制           |                                                       | - `public`：基类成员保持原访问级别<br>- `protected`：基类 `public`/`protected` 成员变为 `protected`<br>- `private`：基类所有成员变为 `private` |
|            | 构造与析构         |                                                       | - 派生类构造函数隐式调用基类构造函数（无参数时）<br>- 构造顺序：先基类后派生类<br>- 析构顺序：先派生类后基类（逆序）                           |
| 多态性     | 虚函数             | `virtual ReturnType func() { ... }`                   | 基类声明虚函数，派生类可重写（覆盖），通过基类指针/引用实现动态绑定                                                                            |
|            | 纯虚函数           | `virtual ReturnType func() = 0;`                      | 声明抽象类，派生类必须实现该函数，否则仍为抽象类                                                                                               |
|            | 动态绑定           | `Base* ptr = new Derived(); ptr->func();`             | 若 `func()` 为虚函数，则调用派生类的实现，实现运行时多态                                                                                       |
| 继承特性   | 重写（覆盖）       | `ReturnType func() override { ... }`                  | C++11 引入，显式标记覆盖基类虚函数，编译器可检查签名一致性                                                                                     |
|            | `final` 关键字     | `virtual ReturnType func() final { ... }`             | 禁止派生类重写该虚函数，防止进一步覆盖                                                                                                         |
|            | 隐藏（覆盖）       | `void func(int);` 隐藏基类 `void func(double);`       | 派生类声明同名函数，隐藏基类同名但参数不同的函数，需用作用域解析符访问基类成员                                                                 |
| 组合与聚合 | 组合（Has-A）      | `class A { B b; };`                                   | 强拥有关系，A 的生命周期包含 B 的生命周期，B 随 A 创建和销毁                                                                                   |
|            | 聚合（Uses-A）     | `class A { B* b; };`                                  | 弱拥有关系，A 仅持有 B 指针，不负责 B 的生命周期管理                                                                                           |
| 继承层次   | 多重继承           | `class Derived : public Base1, public Base2 { ... };` | 派生类同时继承多个基类，可能导致菱形继承（二义性、重复继承）                                                                                   |
|            | 虚继承             | `class Derived : virtual public Base { ... };`        | 解决菱形继承问题，多个派生类共享同一个基类实例，避免重复继承                                                                                   |
| 访问控制   | 访问基类成员       | `obj.baseMember`                                      | 派生类对象可直接访问基类成员，若被隐藏可用作用域解析符 `obj.Base::baseMember`                                                                  |
|            | 作用域解析符       | `Derived::Base::func();`                              | 用于调用基类的静态成员或被隐藏的成员函数                                                                                                       |
| 对象模型   | 基类子对象         | 派生类对象包含基类子对象                              | 派生类对象内存布局：先基类子对象，后派生类成员                                                                                                 |
|            | 虚函数表（vtable） | 每个含虚函数的类有独立的 vtable                       | vtable 存储虚函数地址，支持动态绑定，派生类可重写虚函数，vtable 指向新的实现                                                                   |

- 多态性确实依赖虚函数机制，只有通过基类指针或引用调用虚函数，才会发生动态绑定，调用派生类实现。
- 菱形继承会导致基类成员重复，需通过虚继承让所有派生类共享同一个基类实例，解决二义性。
- 访问控制主要在编译阶段生效，运行时可通过强制类型转换访问被隐藏成员，但这样做不安全且不推荐，可能导致未定义行为。
