# 多态

| 类别     | 核心概念               | 语法 / 关键机制                                               | 说明与目的                                                                       |
| :------- | :--------------------- | :------------------------------------------------------------ | :------------------------------------------------------------------------------- |
| 基础概念 | 多态定义               | 同一接口（函数名）在不同上下文中表现出不同的行为。            | 提高代码的可复用性和可扩展性。                                                   |
|          | 编译时多态（静态多态） | 函数重载、运算符重载、模板                                    | 编译阶段根据参数类型等确定调用哪个函数。                                         |
|          | 运行时多态（动态多态） | 虚函数                                                        | 运行时根据对象实际类型确定调用哪个函数。通常所说的多态即指此种。                 |
| 实现机制 | 虚函数                 | `virtual ReturnType funcName(Params);`                        | 在基类中声明，支持动态绑定。                                                     |
|          | 重写（覆盖）           | `ReturnType funcName(Params) override;`                       | 派生类重新定义基类虚函数，实现特定行为。`override`（C++11）确保正确重写。        |
|          | 纯虚函数与抽象类       | `virtual ReturnType funcName(Params) = 0;`                    | 含纯虚函数的类为抽象类，不能实例化，仅用于定义接口。                             |
|          | 动态绑定的条件         | 1. 基类指针或引用</br>2. 调用虚函数</br>3. 实际指向派生类对象 | 三个条件缺一不可，才能实现运行时多态。                                           |
| 核心组件 | 虚函数表（vtable）     | 每个多态类一个，编译期创建                                    | 存储该类所有虚函数地址的数组。                                                   |
|          | 虚函数表指针（vptr）   | 每个对象一个，构造时初始化                                    | 指向 vtable 的指针，是对象的一部分。                                             |
| 关键操作 | 向上转型               | `Base* ptr = new Derived();`                                  | 派生类指针/引用转换为基类指针/引用，安全且常用。                                 |
|          | 向下转型               | `Derived* derPtr = dynamic_cast<Derived*>(basePtr);`          | 基类指针/引用转换为派生类指针/引用，需 `dynamic_cast` 检查，失败返回 `nullptr`。 |
|          | 析构函数与多态         | `virtual ~Base() { ... }`                                     | 基类析构函数必须为虚函数，才能通过基类指针正确释放派生类对象，避免资源泄漏。     |
| 类型识别 | `typeid` 运算符        | `typeid(*obj).name()`                                         | 获取对象实际类型信息，常用于调试和类型检查。                                     |
|          | `dynamic_cast`         | `Derived* d = dynamic_cast<Derived*>(basePtr);`               | 安全向下转型，失败返回 `nullptr`。                                               |
| 设计原则 | 开闭原则               | 对扩展开放，对修改关闭。                                      | 通过增加新的派生类扩展功能，无需修改依赖基类的现有代码。                         |
|          | 依赖倒置原则           | 依赖于抽象（基类），而非具体实现（派生类）。                  | 多态是实现该原则的关键技术，提升系统灵活性和可维护性。                           |
