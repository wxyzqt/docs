# 数据类型

| 分类       | 类型名称             | 典型大小     | 值范围/说明                                                      |
| ---------- | -------------------- | ------------ | ---------------------------------------------------------------- |
| 布尔型     | `bool`               | 1 字节       | `true` 或 `false`                                                |
| 字符型     | `char`               | 1 字节       | -128 到 127（有符号）或 0 到 255（无符号）                       |
|            | `wchar_t`            | 2 或 4 字节  | 宽字符（Unicode，平台相关）                                      |
|            | `char16_t`           | 2 字节       | UTF-16 字符（C++11 标准）                                        |
|            | `char32_t`           | 4 字节       | UTF-32 字符（C++11 标准）                                        |
| 整型       | `short`              | 2 字节       | -32,768 到 32,767                                                |
|            | `int`                | 4 字节       | -2,147,483,648 到 2,147,483,647                                  |
|            | `long`               | 4 或 8 字节  | 平台相关（32 位为 4 字节，64 位为 8 字节）                       |
|            | `long long`          | 8 字节       | -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807（C++11） |
| 浮点型     | `float`              | 4 字节       | 约 ±3.4e±38（7 位有效数字）                                      |
|            | `double`             | 8 字节       | 约 ±1.7e±308（15 位有效数字）                                    |
|            | `long double`        | 8/12/16 字节 | 约 ±1.1e±4932（19 位有效数字，平台相关）                         |
| 无符号整型 | `unsigned short`     | 2 字节       | 0 到 65,535                                                      |
|            | `unsigned int`       | 4 字节       | 0 到 4,294,967,295                                               |
|            | `unsigned long`      | 4 或 8 字节  | 平台相关                                                         |
|            | `unsigned long long` | 8 字节       | 0 到 18,446,744,073,709,551,615（2⁶⁴-1）                         |
| 空类型     | `void`               | —            | 无类型，用于函数返回类型或指针                                   |
