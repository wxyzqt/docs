# 运算符

## 分类

| 类别       | 运算符                                                                   | 名称/描述          | 示例                                | 可重载性 |
| ---------- | ------------------------------------------------------------------------ | ------------------ | ----------------------------------- | -------- |
| 算术运算符 | `+`                                                                      | 加法               | `c = a + b;`                        | 是       |
|            | `-`                                                                      | 减法               | `c = a - b;`                        | 是       |
|            | `*`                                                                      | 乘法               | `c = a * b;`                        | 是       |
|            | `/`                                                                      | 除法               | `c = a / b;`                        | 是       |
|            | `%`                                                                      | 取模（求余）       | `c = a % b;`                        | 是       |
|            | `++`                                                                     | 自增               | `a++;` 或 `++a;`                    | 是       |
|            | `--`                                                                     | 自减               | `a--;` 或 `--a;`                    | 是       |
| 关系运算符 | `==`                                                                     | 等于               | `if (a == b)`                       | 是       |
|            | `!=`                                                                     | 不等于             | `if (a != b)`                       | 是       |
|            | `>`                                                                      | 大于               | `if (a > b)`                        | 是       |
|            | `<`                                                                      | 小于               | `if (a < b)`                        | 是       |
|            | `>=`                                                                     | 大于等于           | `if (a >= b)`                       | 是       |
|            | `<=`                                                                     | 小于等于           | `if (a <= b)`                       | 是       |
| 逻辑运算符 | `&&`                                                                     | 逻辑与             | `if (a && b)`                       | 是       |
|            | `\|\|`                                                                   | 逻辑或             | `if (a \|\| b)`                     | 是       |
|            | `!`                                                                      | 逻辑非             | `if (!a)`                           | 是       |
| 位运算符   | `&`                                                                      | 按位与             | `c = a & b;`                        | 是       |
|            | `\|`                                                                     | 按位或             | `c = a \| b;`                       | 是       |
|            | `^`                                                                      | 按位异或           | `c = a ^ b;`                        | 是       |
|            | `~`                                                                      | 按位取反           | `c = ~a;`                           | 是       |
|            | `<<`                                                                     | 左移               | `c = a << 2;`                       | 是       |
|            | `>>`                                                                     | 右移               | `c = a >> 2;`                       | 是       |
| 赋值运算符 | `=`                                                                      | 赋值               | `a = b;`                            | 是       |
|            | `+=`                                                                     | 加后赋值           | `a += b;`                           | 是       |
|            | `-=`                                                                     | 减后赋值           | `a -= b;`                           | 是       |
|            | `*=`                                                                     | 乘后赋值           | `a *= b;`                           | 是       |
|            | `/=`                                                                     | 除后赋值           | `a /= b;`                           | 是       |
|            | `%=`                                                                     | 取模后赋值         | `a %= b;`                           | 是       |
| 其他运算符 | `?:`                                                                     | 条件（三元）运算符 | `max = (a > b) ? a : b;`            | 否       |
|            | `,`                                                                      | 逗号运算符         | `c = (a, b);`                       | 是       |
|            | `&`                                                                      | 取地址             | `int* p = &a;`                      | 否       |
|            | `*`                                                                      | 解引用             | `int b = *p;`                       | 否       |
|            | `sizeof`                                                                 | 求大小             | `int s = sizeof(a);`                | 否       |
|            | `::`                                                                     | 作用域解析         | `std::cout;`                        | 否       |
|            | `.*`</br>`->*`                                                           | 成员指针访问       | `obj.*ptr;`</br>`obj->*ptr;`        | 是       |
|            | `typeid`                                                                 | 类型信息           | `typeid(a).name()`                  | 否       |
|            | `dynamic_cast`</br>`static_cast`</br>`const_cast`</br>`reinterpret_cast` | 类型转换           | `dynamic_cast<Derived*>(basePtr)`   | 否       |
|            | `new`</br>`new[]`</br>`delete`</br>`delete[]`                            | 动态内存管理       | `int* p = new int;`</br>`delete p;` | 是       |

## 运算符优先级

| 优先级 | 运算符                                                | 描述                | 结合性   |
| :----- | :---------------------------------------------------- | :------------------ | :------- |
| 1      | `::`                                                  | 作用域解析          | 从左到右 |
| 2      | `a++` `a--`                                           | 后缀自增/自减       | 从左到右 |
|        | `type()` `type{}`                                     | 函数风格类型转换    | 从左到右 |
|        | `()`                                                  | 函数调用            | 从左到右 |
|        | `[]`                                                  | 数组下标            | 从左到右 |
|        | `.` `->`                                              | 成员访问            | 从左到右 |
| 3      | `++a` `--a`                                           | 前缀自增/自减       | 从右到左 |
|        | `+a` `-a`                                             | 一元加/减           | 从右到左 |
|        | `!` `~`                                               | 逻辑非 / 按位取反   | 从右到左 |
|        | `(type)`                                              | C 风格类型转换      | 从右到左 |
|        | `*a`                                                  | 解引用              | 从右到左 |
|        | `&a`                                                  | 取地址              | 从右到左 |
|        | `sizeof`                                              | 取大小              | 从右到左 |
|        | `co_await`                                            | 协程等待 (C++20)    | 从右到左 |
|        | `new` `new[]` `delete` `delete[]`                     | 动态内存分配/释放   | 从右到左 |
| 4      | `.*` `->*`                                            | 成员指针访问        | 从左到右 |
| 5      | `a*b` `a/b` `a%b`                                     | 乘、除、取模        | 从左到右 |
| 6      | `a+b` `a-b`                                           | 加、减              | 从左到右 |
| 7      | `<<` `>>`                                             | 按位左移/右移       | 从左到右 |
| 8      | `<=>`                                                 | 三路比较 (C++20)    | 从左到右 |
| 9      | `<` `<=` `>` `>=`                                     | 关系运算符          | 从左到右 |
| 10     | `==` `!=`                                             | 相等/不等           | 从左到右 |
| 11     | `&`                                                   | 按位与              | 从左到右 |
| 12     | `^`                                                   | 按位异或            | 从左到右 |
| 13     | `\|`                                                  | 按位或              | 从左到右 |
| 14     | `&&`                                                  | 逻辑与              | 从左到右 |
| 15     | `\|\|`                                                | 逻辑或              | 从左到右 |
| 16     | `a?b:c`                                               | 三元条件            | 从右到左 |
|        | `throw` `co_yield`                                    | 抛出异常 / 协程产出 | 从右到左 |
|        | `=`                                                   | 赋值                | 从右到左 |
|        | `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\| =` | 复合赋值            | 从右到左 |
| 17     | `,`                                                   | 逗号                | 从左到右 |
