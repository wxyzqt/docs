# 流程控制

| 类别     | 控制符/语句                       | 说明                                               |
| :------- | :-------------------------------- | :------------------------------------------------- |
| 条件语句 | `if`                              | 根据条件判断执行代码块。                           |
|          | `else`                            | 与 `if` 配合，条件为假时执行。                     |
|          | `else if`                         | 检查多个条件分支。                                 |
|          | `switch`                          | 根据表达式的值选择执行分支。                       |
|          | `case`                            | 在 `switch` 中定义匹配的常量分支。                 |
|          | `default`                         | `switch` 中无匹配时执行的分支。                    |
| 循环语句 | `for`                             | 已知循环次数时使用，重复执行代码块。               |
|          | `while`                           | 条件为真时循环，先判断条件再执行。                 |
|          | `do...while`                      | 条件为真时循环，先执行一次再判断条件。             |
|          | 范围 for (`for (auto x : range)`) | C++11 引入，遍历序列（如数组、容器）中的每个元素。 |
| 跳转语句 | `break`                           | 终止当前循环或 `switch` 语句。                     |
|          | `continue`                        | 跳过本次循环剩余部分，进入下一次循环。             |
|          | `return`                          | 从函数返回，可带返回值。                           |
|          | `goto`                            | 跳转到函数内指定标签（不推荐，易导致代码混乱）。   |

- 条件语句：决策。
- 循环语句：重复执行任务。
- 跳转语句：改变默认的执行顺序。
