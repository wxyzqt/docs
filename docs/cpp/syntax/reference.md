# 引用

| 知识类别   | 语法/示例                                                                       | 核心特性与说明                                                                                              |
| :--------- | :------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------- |
| 基本概念   | `类型 &引用名 = 原变量名;`                                                      | 1. 引用是变量的别名。</br>2. 声明时必须初始化，绑定已有变量。</br>3. 初始化后不可再绑定其他变量。           |
| 基本用法   | `int a = 10;`</br>`int &ref = a;`</br>`ref = 20; // a的值也变为20`              | 通过引用`ref`修改值，等价于直接修改`a`。                                                                    |
| 常量引用   | `const int &ref = a;`</br>`// ref = 30; // 错误！不能通过ref修改a`              | 1. 只读访问，保证原值不被修改。</br>2. 可绑定常量或临时对象，拓宽使用场景。                                 |
| 函数参数   | `void swap(int &x, int &y);`                                                    | 1. 传递引用，函数内修改形参会影响实参。</br>2. 适合大型结构或类对象，避免拷贝，提高效率。                   |
| 函数返回值 | `int& getElement(vector<int> &arr, int index);`                                 | 1. 可返回静态变量、动态分配对象或参数的引用。</br>2. 切勿返回局部变量引用，否则会悬空引用，导致未定义行为。 |
| 与指针对比 | 引用：别名，无需解引用，更安全。</br>指针：存储地址，可重指向，可为空，更灵活。 | 引用底层通常通过指针实现，但语法更简洁，安全性更高。                                                        |
