## 当前学习计划

掌握 C++ 基础语法（变量、数据类型、运算符、流程控制）。

学习函数、数组、字符串、指针和引用。

理解面向对象编程（类、对象、继承、多态、虚函数、构造/析构函数）。

熟悉标准库（STL：vector、map、set、string、智能指针）。

掌握文件读写、异常处理。

了解 C++11/14/17 新特性（auto、lambda、智能指针、范围 for 循环等）。

能独立编写中等复杂度的 C++ 项目。

学习 Qt 基础（信号与槽、界面设计、事件处理）。

用 C++ 在 Qt 中实现简单的界面和逻辑。
