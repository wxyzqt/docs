# utf-32

定长 4 字节编码，浪费空间，速度优先，顺序易测

| 特性     | UTF-32             | UTF-16         | UTF-8              |
| :------- | :----------------- | :------------- | :----------------- |
| 长度     | 固定 4 字节        | 2 或 4 字节    | 1-4 字节           |
| 兼容性   | 无                 | 部分兼容 BMP   | 完全兼容 ASCII     |
| 适用场景 | 内存计算、特殊字符 | 系统级文本处理 | 网络传输、通用存储 |
