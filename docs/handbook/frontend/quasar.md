# Quasar

## 链接

国内基于 vue3 很好用的框架或者库有不少，单独记录这个有以下因素：

- Quasar 提供了足够多的内置功能，在开发时，心智模型相对统一
- Quasar 在目标上想要实现一套心智模型创建多端的界面（当然不是指一个仓库对应多端，那就是灾难！）
- 早在 2020 年左右，印象里当时这个库的 star 只有几千，开发团队也才两三个人
- 现在，开发团队已经有近 10 人，各个岗位都有专人负责。也就是说已经是一个成熟的项目
- 如果说我早生几年，或者天赋水平高一些，存在那么一点点可能会和 quasar 作者走一样的道路
- 国内用这个的很少听到，但 quasar 确实在技术和工程构想方面走在了绝大多数前端库的前面，并且走通了这条路。
- 影响该仓库在国内推广因素有二：一、主要为英文文档；二、前置要求偏高，至少目前市场上所谓的中级前端和相当一部分高级前端未必能领会其`价值观`。
- 单独提出来不只是出于技术同感，而是其实际价值已经能够凸显，就看挑选的人眼光如何。
