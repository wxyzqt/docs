# 硬件认知

以个人 pc 为例，核心硬件有：主板、cpu、内存(ARM)、存储(软盘、硬盘-固态或机械)、扩展插槽(显卡、声卡、网卡)。

- 主板连接各核心部件，通过`总线`传递信号。

`总线`是计算机内部各部件之间传输数据的公共通道，是一组信号线的集合。

代码中展现的 0 和 1 就是通过总线在各个部件之间传递。

- 很多硬件单元都有自己的`寄存器`，最核心的寄存器位于 cpu 内部，寄存器的位数是 cpu 架构位数的主要参考因素。

- 机械硬盘 CHS 式存储、固态硬盘通过 FTL 处理，将不同类型的存储介质地址转化为 LBA(线性地址序列)。

这是代码中地址从 0x0 到 0xffffffff 按序访问存在的基础。

- CPU 有一个专门的地址空间，称为`I/O端口空间`。它和内存地址空间是分开的。CPU 使用专门的指令（如 x86 中的 IN 和 OUT 指令）来访问这个空间。

```asm
IN AL, 0x60 ; 意为从端口地址 0x60 读取一个字节到 AL 寄存器。
```

:::tip
端口概念分为三大类：

- 硬件实体，usb 接口、网线接口、耳机插孔...
- I/O 端口，用于 CPU 与 I/O 设备通信的 ‌ 地址，os 内核中的端口指的就是这种
- 软件端口，软件协议层面的端口，`http://localhost:9999`，9999 就是端口

:::

`操作系统`就是管理和分配硬件资源的软件，也是硬件与软件的中间层。

对硬件来说，操作系统抽象了硬件功能，对软件来说，是运行常规软件的基础环境。

要明白，我们学习操作系统的目的并非是要自己弄出一个优秀的 os，而是从根本上理解`硬件与软件交互的逻辑`以及`应用软件运行的基建环境`，进而理解软件的长处与限制，知其所以然。
