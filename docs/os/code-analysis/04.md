# 从磁盘扇区加载数据

引导扇区大家已经知道了，就是特指第一个扇区。

那么后续扇区是怎么加载的呢？

`boot/disk.asm`中，符号`disk_load`内

```asm
    mov ah, 0x02 ; int 0x13是BIOS的磁盘中断服务, 功能号0x02是读取扇区
    mov al, dh   ; al，要读取的扇区数量，这里读取扇区数已经由dh给了al
    mov cl, 0x02  ; 0x01 是boot扇区, 0x02 是第一个可用扇区
    mov ch, 0x00 ; ch 柱面号取值范围0x0-0x3FF，即0-1023
    mov dh, 0x00 ; dh 盘面号(Head) 取值范围0x0-0xF，即0-15，这里dh重新设为0表示使用第0个盘面

    int 0x13      ; BIOS 中断调用以执行磁盘读取操作
```

`int 0x02`和`int 0x13`大家可以通过[中断](../list/interrupt.md)去理解，还记得[硬件认知中](./01.md)关于`I/O 端口`的部分么？

`mov al, dh`,将寄存器`dh`的值传递给寄存器`al`,`dh`的值是符号`disk_load`外设置的，这里只是将寄存器`dh`作为参数存值的地方。

下面代码涉及到一个概念叫 CHS 寻址

```asm
    mov cl, 0x02
    mov ch, 0x00
    mov dh, 0x00
```

## CHS 寻址

CHS:Cylinder Head Sector,磁柱磁头扇区寻址。

柱面：Cylinder

磁头(盘面号)：Head

扇区:Sector

早期存储设备就是软盘硬盘，两者都是圆形盘片设计。

### 寻址参数范围

CHS 寻址的三个参数及其最大取值范围如下：

柱面数（Cylinders）‌
最大 1023（10 位二进制存储，从 0 开始编号）‌

磁头数（Heads）‌
最大 255（8 位二进制存储，从 0 开始编号）‌

扇区数（Sectors）‌
最大 63（6 位二进制存储，从 1 开始编号）‌

## 小结

所以`disk_load`作用很简单，CHS 参数设置进寄存器，而后调用中断，读取磁盘，将 0 柱面，0 磁头，2 扇区的内容加载到内存中。
