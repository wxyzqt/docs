# 从汇编开始

## 第一个汇编程序

```asm

bits 16             ; 16位实模式
org 0x7C00          ; BIOS加载引导扇区到0x7C00

start:
    ; 设置段寄存器
    xor ax, ax
    mov ds, ax
    mov es, ax
    mov ss, ax
    mov sp, 0x7C00

    ; 清屏
    mov ax, 0x0003
    int 0x10

    ; 显示消息
    mov si, msg
    call print_string

    ; 无限循环
    jmp $

print_string:
    ; 打印以0结尾的字符串
    mov ah, 0x0E
.loop:
    lodsb
    test al, al
    jz .done
    int 0x10
    jmp .loop
.done:
    ret

msg db 'Hello, OS World!', 0

; 引导扇区填充
times 510-($-$$) db 0
dw 0xAA55         ; 引导扇区标识

```

乍一看内容有点多，分解一下知识点。

首先，汇编语言采用 nasm 语法与我们写的 js 和 c 等代码并无不同，都是一种程序语言。

而汇编主要用途在直接操作寄存器和中断上。

上述代码开头

```asm
bits 16
```

表明这是 16 位寄存器，寄存器位数的意义在于一次性处理数据的位宽度。

这一行附带隐含信息还有 2 个：20 位地址总线，以及真实模式。

计算机发展是随科技进步而来的，最早的 x86 系列， Intel 8086 就是 16 位寄存器，其配套的地址总线位数为 20。

地址总线代表内存访问能力，2 的 20 次方即 1M 内存空间。

`重点`：不论是 16 位还是 32 位寄存器都存在真实模式和保护模式。不过，非特指标明的情况下，`bits 16`即 16 位寄存器，20 位地址总线，真实模式。`bits 32`即 32 位寄存器，32 位地址总线，保护模式。

### 问题 1

上述 16 位寄存器一次性处理 16 位数据，那是怎么处理 20 位地址总线的地址呢？

答案是：物理地址 = (段寄存器值 << 4) + 偏移量

段寄存器 CS、DS 等存储 16 位数据，左移 4 位后，加上 IP 或 SI 存储的 4 位数据，即得到 20 位地址。

:::info 示例
CS（代码段寄存器）+ IP（指令指针）

CS=0x1000, IP=0x0100 → 物理地址 0x10000 + 0x0100 = 0x10100
:::

16 进制一个位等于 2 的 4 次方，16 位即 4 个 16 进制数据，20 位即 5 个。

### 问题 2

第 2 行`org 0x7C00` 是汇编器伪指令，用于指定代码或数据的 ‌ 内存起始地址 ‌。

具体来说将本文件写的代码加载到指定 0x7c00 这个内存地址位置。

为什么是 0x7c00 这个地址，这只是一种规范，为不同功能划分不同地址区间，就是这么简单。

如果最开始是你设计，完全也可以设置到 0x8c00 或者其他位置。

注意到第 2 行注释`引导扇区`这个词么，这就要求我们的文件要符合引导扇区的特征：总共 512 字节，以及特征结尾`dw 0xAA55`。

`dw 0xAA55`转化为二进制的信号`0b10101010 01010101`这一对称性方便硬件检测。

:::tip
x86 内存采用小端序，即低位字节存储在低地址，高位字节存储在高地址。

| 内存地址 ‌ | ‌ 存储值 ‌ | ‌ 二进制表示 ‌ |
| :--------- | :--------- | :------------- |
| 0x0000     | 0x55       | 01010101       |
| 0x0001     | 0xAA       | 10101010       |

所以在内存中，`dw 0xAA55`存储为`01010101 10101010`
:::

早期磁盘技术，硬件上为平衡存储效率和寻址速度，设定为 512 字节为一个扇区，这一设定延用下来。

我们的代码中是如何实现 512 字节的？

```asm
; 引导扇区填充
times 510-($-$$) db 0
```

`times 510` 表示重复 510 次

`db 0` 表示每次重复写入 0

`$` 当前代码位置地址

`$$` 当前代码段的起始地址,这里是`0x7c00`

剩下的其实就是语法和操作寄存器的内容，这些请参考[nasm](../../assembly/nasm.md)和[寄存器](../../assembly/register.md)
