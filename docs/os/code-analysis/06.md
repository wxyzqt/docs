# 开始 c 语言的内核部分

os 仓库`boot/kernel_entry.asm`文件中指定了 c 环境下的入口函数名`kernel_main`,

跳转到`kernel/kernel.c`文件内容，这时候，已经可以开始用 c 语言来写代码。

主要注意的是此时 c 运行时库还未构建，即部分库不能使用。

## 何时使用 c 标准库

判断 C 语言标准库是否独立于运行时环境，主要看它是否需要底层系统支持动态内存管理

在操作系统开发中，C 语言在完成基本的运行时环境初始化后就可以使用标准库了。

具体来说，需要先实现以下几个关键步骤：

### 核心前提条件

内存管理就绪 ‌

实现 `malloc()/free()`等动态内存分配函数

建立堆空间管理机制，为库函数提供内存支持

### 系统调用封装 ‌

将内核的系统调用封装成 C 库可识别的接口

例如实现`_write()`、`_read()`等底层 I/O 函数

### 启动代码完善 ‌

完成`_start` 等入口函数的初始化工作
设置好栈指针、全局变量初始化等环境

## 标准库的分阶段使用

### 早期阶段可用

`<stddef.h>`、`<stdint.h>`：类型定义

`<string.h>`：内存操作、字符串处理

`<ctype.h>`：字符类型判断

### 环境完善后可用

`<stdio.h>`：文件操作、格式化输出（需文件系统支持）

`<stdlib.h>`：动态内存管理、环境变量

`<math.h>`：数学运算（需浮点单元支持）
