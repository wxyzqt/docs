# GDT 与 LDT 对比表格

| 特性         | ‌ ‌ 全局描述符表(GDT)‌ ‌             | 局部描述符表(LDT)‌                      |
| :----------- | :----------------------------------- | :-------------------------------------- |
| 作用范围     | ‌ 全局共享，所有任务共用             | 任务私有，每个任务独立拥有              |
| 描述符数量   | ‌ 最多 8191 个（索引 0 保留）‌       | 最多 8192 个（索引 0 有效）‌            |
| 访问控制     | ‌ 通过段选择子 TI 位=0 标识          | ‌ 通过段选择子 TI 位=1 标识 ‌           |
| 权限隔离     | ‌ 统一管理内核段和共享段权限         | ‌ 实现任务间段隔离，保护私有数据 ‌      |
| 典型用途     | ‌ 定义代码段、数据段、TSS 等全局资源 | ‌ 存储任务私有段（如用户态代码/数据）‌  |
| 寄存器关联 ‌ | 由 GDTR 寄存器指向                   | ‌ 由 LDTR 寄存器指向（任务切换时更新）‌ |
