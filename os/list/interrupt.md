# 中断

中断是处理器响应外部事件或内部错误的机制，在实模式和保护模式下作用基本相同，分为两类：

- 硬件中断 ‌：由外设（如键盘、磁盘）通过中断控制器（如 APIC）触发，请求 CPU 服务，具有随机性和异步性 ‌
- 异常 ‌：CPU 执行指令时检测到的错误（如除零、页故障），属于同步事件，需立即处理 ‌

## 硬件中断机制

- 中断控制器 ‌：如 8259A 或 APIC，将外设信号转换为中断向量 ‌
- 中断门 ‌：IDT 中的描述符，存储中断处理程序地址和权限信息 ‌
- 处理流程 ‌：CPU 完成当前指令后，根据中断向量跳转至 IDT 对应门，执行处理程序 ‌

## 异常处理机制

- 故障（Fault）‌：可纠正错误（如缺页），处理器自动回退指令重试 ‌
- 陷阱（Trap）‌：调试或条件检查（如 INT 3 断点指令）‌
- 机器检查 ‌：硬件错误（如总线故障），通常不可恢复 ‌

## 两种模式中断对比

| 对比维度 ‌     | ‌ 实模式 ‌                                                          | ‌ 保护模式 ‌                                                                |
| :------------- | :------------------------------------------------------------------ | :-------------------------------------------------------------------------- |
| 中断向量表 ‌   | 固定位置（0x0000:0x0000），每个中断向量占 4 字节（段地址:偏移地址） | 可动态配置的中断描述符表 （IDT），每个描述符占 8 字节，支持特权级和类型检查 |
| 寻址能力 ‌     | 仅支持 1MB 物理地址空间，中断处理程序需位于低端内存                 | 支持 4GB 线性地址空间，中断处理程序可位于任意内存位置                       |
| 特权级控制 ‌   | 无特权级概念，所有代码运行在最高权限（Ring 0）                      | 支持 4 个特权级（Ring 0-3），中断门可指定目标特权级（DPL）                  |
| 中断响应流程 ‌ | 直接跳转至中断向量表地址，无额外检查                                | 需验证中断门描述符的 DPL 和当前特权级（CPL），可能触发特权级切换            |
| 异常处理       | 通过固定中断向量处理，无任务切换机制                                | 支持任务门（Task Gate），可触发任务切换（如 TSS 切换）                      |
| 典型应用场景 ‌ | 早期 DOS 系统、简单嵌入式系统                                       | 现代操作系统（如 Windows/Linux）、多任务环境                                |

## BIOS 中断表

还记得内存布局`0x00000`位置 1KB 大小内存的 BIOS 中断向量表（256 个）么？

每一个中断 4 字节（2 字节段地址 + 2 字节偏移地址）

### 核心功能中断（00h-1Fh）

CPU 异常处理（不可屏蔽）

| INT 号 | 功能说明       | 典型用途                   |
| :----- | :------------- | :------------------------- |
| 00h    | 除零错误处理   | CPU 检测到除零操作时触发 ‌ |
| 04h    | 溢出错误处理   | 算术运算结果溢出时触发     |
| 06h    | 无效操作码异常 | CPU 遇到非法指令时触发     |
| 09h    | 浮点错误处理   | FPU 执行无效浮点操作时触发 |
| 10h    | 视频服务       | 图形模式设置/字符显示 ‌    |
| 13h    | 磁盘服务       | 硬盘/软盘读写操作          |
| 16h    | 串行端口服务   | 串口通信控制               |
| 17h    | 并行端口服务   | 并口数据传输控制           |

### 扩展功能中断（20h-FFh）

可编程中断（IRQ0-IRQ15 映射），外设/系统调用

| INT 号 | 功能说明           | 典型用途              |
| :----- | :----------------- | :-------------------- |
| 21h    | 系统调用           | DOS/BIOS 系统服务入口 |
| 25h    | 打印服务           | 打印机状态检查        |
| 2Eh    | 可加载中断服务程序 | 动态加载中断处理程序  |
| 30h    | 时钟服务           | 系统时间/闹钟设置     |
| 40h    | 端口操作           | 直接 I/O 端口访问     |
| 70h    | 硬件中断入口       | 系统保留中断          |
| 80h    | 日期时间服务       | RTC 时钟读取/设置     |
| F0h    | 系统保留中断       | 扩展功能预留          |
