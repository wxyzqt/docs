# 文件系统

很明显，直接从磁盘扇区加载数据不灵活：数据归属，数据跨扇区，数据增改都是难题。

这时候，文件系统便抽象了出来。

文件系统部分主要解决两个问题：将磁盘的 CHS 读取转换为 LBA 读取，即屏蔽特定物理结构，转换为线性地址；以文件的形式区分数据，便于管理。

## FAT12

BPB 是 BIOS 读取的。它位于引导扇区（如 DBR 或 OBR）中，包含分区关键参数（如每扇区字节数、磁头数等），BIOS 在启动时会读取这些信息以初始化磁盘操作 ‌

BPB:BIOS parameter block‌,BIOS 参数块

DBR:DOS Boot Record,DOS 引导记录

OBR:OS Boot Record,OS 引导记录

### 关键参数

定义 FAT12 文件系统的关键参数：

每扇区 512 字节

每簇 1 个扇区

2 个 FAT 表，每个占 9 个扇区

根目录 224 个条目

总扇区数 2880（1.44MB 软盘）

### 磁盘读取核心功能

ReadSectors 例程:

重试机制 ‌：设置 5 次重试计数器

扇区转换 ‌：调用 LBACHS 将 LBA 转换为 CHS 格式

‌BIOS 读取 ‌：使用 INT 0x13 AH=0x02 读取单个扇区

错误处理 ‌：读取失败时重置磁盘并重试

进度显示 ‌：成功读取后显示进度点

LBACHS 转换逻辑：

将逻辑扇区号转换为物理磁盘的柱面-磁头-扇区地址:

绝对扇区 ‌ = (LBA / 每磁道扇区数) + 1

绝对磁头 ‌ = (LBA / 每磁道扇区数) MOD 磁头数

绝对磁道 ‌ = LBA / (每磁道扇区数 × 磁头数)

ClusterLBA 转换：

将 FAT 簇号转换为 LBA 地址：

‌LBA‌ = (簇号 - 2) × 每簇扇区数 + 数据区起始扇区
