# 收尾

进入到 c 语言开发之后，基本已经回到大家熟悉的常规开发领域。

诸如保护模式下内存管理、内存分页、进程、线程之类的内容不想讲太多，因为这类文章比比皆是，大体上讲的差不多，我不想再重复。

到这里，操作系统这个仓库想要学习的东西可以告一段落。

了解数据的产生、处理、交互的原理细节，才是这个仓库想要说的东西。

学习操作系统是一个“去魅”的过程：很多看起来高大上的技术，剥离掉血肉外皮，剩下的核心骨架离不开这些基本原理。

如果读者认真学习了操作系统，结合几年开发经验。

此时应当具备了以下能力：

- 两星期上手一门编程语言
- 具备技术价值和趋势的基本判断力
- 更系统的全瞻视角

最后提示，操作系统内容相当庞杂，并非只靠看一些文章就能理解，还是要自己动手试一下为好。
