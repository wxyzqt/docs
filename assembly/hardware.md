# 硬件认知

计算机所做的事情最原始最底层就是控制 0 和 1，可以转换为元器件的开和关。

最初的振荡器，发展到电子二极管乃至现在的半导体二极管，所做的事情都是控制元器件和电路。

以半导体二极管为例：

电流分别从正负极经过，是否形成回路，受其物理化学性质影响分为了联通和断开两种状态。

将电源、二极管、电阻、电容组合成电路，可以表达与、或、非、异或等门电路。

门电路组合形成半加器、全加器，执行加减乘除运算。

:::tip
早期四则运算全由加法器完成，后面乘法器和除法器独立出来，但核心仍是加法器。
:::

不同门电路也可以组成不同的触发器。

`RS 触发器`
由两个交叉反馈的门电路组成，具有复位(R)和设置(S)两个输入端。当 R 和 S 均为 0 时保持当前状态，R 为 0 且 S 为 1 时置位输出 1，R 为 1 且 S 为 0 时复位输出 0。常用于二进制计数器和寄存器。 ‌

`JK 触发器`
在 RS 触发器基础上增加 J(置位)和 K(复位)输入端，并通过时钟信号控制状态翻转。当 J 为 1 且 K 为 0 时在时钟上升沿置位，K 为 1 且 J 为 0 时复位。常用于序列检测器和分频器。 ‌

`D 触发器`
输入端直接接收数据信号，时钟信号上升沿时将数据锁存到输出端。主要用于数据寄存、移位寄存器和同步系统。 ‌

`T 触发器`
在时钟信号上升沿自动翻转状态(0 变 1 或 1 变 0)，常用于分频器和时序控制电路。 ‌

在触发器和门电路的基础上衍生发展。

运算器，控制器，存储器，输入设备，输出设备，计算机的五大部分由此实现。

## 频率

计算机主频 = 外频 X 倍频

外频：为 cpu 和内存提供基准时钟信号。

倍频：利用非线性器件产生的谐波，通过锁相环(PLL)放大外频倍数。

:::tip 超频
CPU 频率标定值一般在其安全值范围内留有一定余量。

倍频通常是锁定的，超频超的就是外频。

外频可以通过 BIOS 查看。
:::

## 硬盘

按内存寻址方式不同，机械硬盘推荐定期整理碎片，固态硬盘则尽量减少删除文件的次数，以延长使用寿命。
