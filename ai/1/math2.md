# 数学基础

## 定义

数学是研究数量、结构、变化、空间及信息等抽象概念的科学，通过逻辑推理和符号化方法探索模式与真理

## 领域分支

| 核心领域 | 主要分支   | 研究内容                               | 典型应用                 |
| :------- | :--------- | :------------------------------------- | :----------------------- |
| 基础数学 | `代数`     | 研究数系、多项式、群、环、域等抽象结构 | 数论、密码学、物理建模   |
|          | 几何       | 研究形状、空间、流形及其性质           | 建筑、导航、计算机图形学 |
|          | 分析       | 研究变化、极限、`微积分`、函数空间     | 物理、工程、经济学       |
|          | 数论       | 研究整数的性质与规律                   | 密码学、计算机科学       |
| 应用数学 | `概率统计` | 研究随机现象、数据收集与分析           | 金融、保险、生物医学     |

## 基础概念

### 数与代数

核心定义：

- 自然数：表示物体个数的数（0, 1, 2, 3…），0 也是自然数。
- 整数：包括正整数、0、负整数（-1, -2, -3…）。
- 有理数：所有能化成分数形式的数，包括整数、有限小数和无限循环小数。
- 无理数：无限不循环小数，如 π、√2。
- 相反数：只有符号不同的两个数，0 的相反数是 0。
- 绝对值：一个数在数轴上对应点到原点的距离，非负。

常见易错点：

- 混淆有理数与无理数的概念，误认为无限小数都是无理数。
- 忽略 0 既不是正数也不是负数，以及 0 的相反数、绝对值都是 0。
- 实数的运算中，符号判断错误，运算顺序不合理导致结果错误。

### 方程与不等式

核心定义：

- 一元一次方程：只含有一个未知数，且未知数的最高次数是 1 的整式方程。
- 一元二次方程：形如 ax² + bx + c = 0 (a≠0)的方程。
- 不等式：表示不等关系的式子，解是使不等式成立的未知数的值。

常见易错点：

- 解分式方程时，忘记检验分母不为 0，导致增根。
- 解不等式时，两边同乘或除以负数，忘记改变不等号方向。

### 几何与图形

核心定义：

- 三角形全等：两个三角形的三边和三角分别相等，可用 SSS、SAS、ASA、AAS 判定，A(角，angle)，S(边，side)。
- 勾股定理：直角三角形两直角边的平方和等于斜边的平方。
- 圆：所有到定点（圆心）距离相等的点的集合。

常见易错点：

- 混淆全等三角形和相似三角形的判定条件。
- 计算圆的弧长和扇形面积时，公式使用错误或单位不统一。

### 统计与概率

核心定义：

- 平均数：一组数据的和除以数据的个数。
- 中位数：将一组数据按大小排列后，位于中间的数。
- 概率：事件发生的可能性大小，取值范围在 0 到 1 之间。

常见易错点：

- 混淆平均数、中位数和众数的概念和适用场景。
- 计算概率时，样本空间考虑不全面，导致概率计算错误。
- 绘制统计图表时，数据分类不准确，图表选择不当。
